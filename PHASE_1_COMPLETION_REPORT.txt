🚀 GETTING STARTED

STEP 1: Run Migrations
  $ php artisan migrate

STEP 2: Seed Roles & Permissions
  $ php artisan db:seed --class=RolePermissionSeeder

STEP 3: Register Routes (in routes/web.php)
  require base_path('routes/saas-phase1.php');

STEP 4: Register Middleware (in app/Http/Kernel.php)
  'resolve_tenant' => \App\Http\Middleware\ResolveTenant::class,
  'check_feature' => \App\Http\Middleware\CheckFeatureAvailable::class,

STEP 5: Start Server
  $ php artisan serve

STEP 6: Access Endpoints
  → http://localhost:8000/admin/tenants
